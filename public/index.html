Tài Liệu Cổng API Miễn Phí

Tool đã mở sẵn 2 dạng API tiện lợi để bạn tích hợp vào bất kỳ dự án hay ứng dụng nào:

POST http://localhost:3000/api/chat

Body (JSON):

{
  "message": "Xin chào ChatGPT!",
  "newChat": false
}

Ví dụ cURL:

curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Viết thơ ngắn về mùa thu"}'

Ví dụ Python:

import requests

url = "http://localhost:3000/api/chat"
payload = {"message": "Xin chào, bạn là ai?"}
res = requests.post(url, json=payload)
print(res.json()["reply"])
POST http://localhost:3000/v1/chat/completions

Tương thích 100% với OpenAI SDK, LangChain, NextChat, OpenWebUI!

Ví dụ Python với OpenAI SDK:

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="anything"  # Không cần API key thực tế
)

response = client.chat.completions.create(
    model="chatgpt-free",
    messages=[{"role": "user", "content": "Tóm tắt định luật Newton"}]
)

print(response.choices[0].message.content)
